# Инструкции Ankora: Happ, INCY и v2rayN

Здесь собраны пошаговые инструкции Ankora для iPhone, Android, Windows и macOS. Выберите своё устройство и приложение, чтобы установить его, добавить подписку и включить подключение.

![Ankora — инструкции для Happ, INCY и v2rayN](images/readme/01.png)

*Ankora — инструкции для Happ, INCY и v2rayN.*

[Открыть Ankora в Telegram](https://t.me/AnkoraNetBot?start=github)

## Как начать

1. Откройте бот Ankora и запустите пробный период.
2. Выберите устройство и подходящее приложение.
3. Установите приложение по ссылке из инструкции.
4. Откройте подписку из бота или добавьте её по скопированной ссылке.
5. Выберите подключение и подтвердите системное разрешение, если устройство его запросит.

Первые 24 часа можно использовать для знакомства с сервисом. Одна подписка работает максимум на трёх устройствах, трафик не ограничен. Доступны локации в Великобритании, США, Финляндии, Франции и Швейцарии.

Happ, INCY и v2rayN — приложения сторонних разработчиков. Ankora предоставляет подписку и помогает добавить её в выбранное приложение.
