# Как добавить подписку в v2rayN на Windows

Для v2rayN используется отдельная ссылка Ankora для Windows. Получите её в боте, импортируйте из буфера обмена и включите выбранное подключение.

[Открыть Ankora и получить ссылку](https://t.me/AnkoraNetBot?start=github)

## Порядок подключения

1. **Подготовьте v2rayN.** В боте Ankora откройте раздел Windows, выберите v2rayN и установите приложение по предложенной ссылке.

2. **Скопируйте ссылку для Windows.** Нажмите на неё на экране подключения Ankora. Не публикуйте эту ссылку и не отправляйте её в общие чаты.

3. **Импортируйте подписку.** Откройте в v2rayN меню `Servers`, затем выберите `Import from clipboard`.

4. **Выберите подключение.** Нажмите на подходящую строку в появившемся списке.

5. **Включите подключение.** Если Windows запросит системное разрешение, подтвердите его.

Актуальная краткая памятка находится на [странице Ankora для v2rayN](https://getankora.app/help/windows/v2rayn/).

[Вернуться в Ankora или обратиться в поддержку](https://t.me/AnkoraNetBot?start=github)
